# 3/4/5 号天体引力势形状规格（源自参考图 3.png / 4.png / 5.png）

本文件是「按参考图重新设计 CRAB PULSAR / CYGNUS X-1 / PROCYON B 三个 profile 的
井形 / 网格 / 机位」的纯文字形状规格，供**不看图**的工程师直接实现。
每张参考图只描述中央 3D 视口里的引力势场景（HUD 顶栏/侧栏不属于本规格范围）。

## 通用约定与读数方法

- **VW** = 中央 3D 视口的宽度，**VH** = 视口高度。文中所有百分比都相对 VW（注明除外）。
- 机位俯仰同时给出两种口径：**仰角**（相机相对平面的上抬角，平视=0°）与
  `polarDeg`（本项目 `types.ts` 约定：自 +Y 轴量起，90°=平视），两者互斥使用其一即可。
- 全部数值为目视估计，容差约 ±15%。实现时以「视觉印象与参考图一致」为最终标准，
  不必死抠绝对数值；比例关系（深度/口径、球/井口）比绝对值更重要。
- 参考图共同点：浅色底 + 黑色细线框网格 + 黑色密集线框球，无任何发光/填色。
  我们的线条/配色保持不变（见文末「我们的保留差异」）。

## 3.png — CRAB PULSAR（中子星）

### a) 井/漏斗整体剖面形状

- **形状族：窄深漏斗 / 喇叭（funnel/trumpet），外衬极宽平坦的裙边。**
- 漏斗口直径 ≈ 30% VW；平面开始下沉的「外裙」过渡带一直展开到 ≈50–55% VW，
  即**很宽的平坦裙边 + 中央一条窄漏斗**。
- **深度量级：漏斗深度（口沿→底部尖点）≈ 55–65% VH ≈ 1.8–2.2 × 漏斗口直径。**
  漏斗是「深大于宽」的，这是它读作强引力井的核心。
- 喉部：底部收成**尖点**（尖端宽度 < 10% 口宽），球坐在尖点附近，尖点还略伸出球底一点。
- 井口**无翻边/无唇**：平面→井壁是一条平滑 S 曲线——先很缓地向下弯，然后井壁逐渐变陡。
- 井壁坡度：**单坡度长锥为主**（锥段接近直线锥，斜率基本恒定，允许上段略缓、下段略陡的
  轻微凹形）；外裙是另一段很浅很宽的缓坡，两者在口沿处平滑相接。
- 平面整体带**大尺度、很缓的起伏**：整张面不是完美平板，而是有横跨整个视口的缓慢鼓包/
  起伏（我们的波浪动画就叠在这一层上）。

### b) 平面（网格地面）的可见范围与边缘处理

- **大盘 / 近无限面**：横向跨度 ≈ 90–100% VW。
- 远端（画面上部）淡出进背景，地平线位于 ≈20–25% VH 处；近端延伸出画面下缘。
- 网格线间距均匀、密度中等偏密；最外圈网格线**透明度逐渐衰减**，没有硬边缘。
- 平面在画面面积中占比 ≈ 60–70%（其余为中央漏斗与上方留白）。

### c) 球体大小与相对井的位置

- 密集线框小球，直径 ≈ 8–10% VW，颜色深、网目密（视觉上接近一团密黑线）。
- 球坐在漏斗 **85–95% 深度处**（近尖底）；漏斗尖点在球底下方再延伸一小段。
- **球 : 漏斗口直径 ≈ 1:4 至 1:5** —— 球明显比井口小很多。

### d) 机位估计

- **低机位、近平视**：仰角 ≈ 15–25°（polarDeg ≈ 65–75°）。
- **中远距离**：整条漏斗（口沿→尖底）与平面远端地平线同时入画。
- 构图：球水平居中、垂直 ≈70–75%（下三分之一）；漏斗口顶部 ≈45–50% VH；
  平面地平线 ≈20–25% VH。球在画面中仅占 ≈8–10% 帧宽，偏小。

### e) 让它读作「正常引力势」的关键视觉特征

一张宽阔平坦的时空薄片，中央被「钻」出一条窄而深的长漏斗，收束成尖点，小星体坐在最底。
关键是**宽平外裙与窄深漏斗的强烈对比**，以及**漏斗深度显著大于口半径**——井若太浅太宽
会读成浅盘，而不是中子星/脉冲星这种强场势阱。

> 实现提示（非硬性）：可用 `funnel` 类项做窄深内芯，外圈叠一个宽而浅的缓坡项
> （或宽半径的 `well` 衰减项）做外裙；`grid.half` 要够大让平面铺满视口，靠雾/透明度淡出远端。

## 4.png — CYGNUS X-1（黑洞）

### a) 井/漏斗整体剖面形状

- **形状族：超长细喇叭 / 细管（三者中最极端的细长漏斗）。**
- 顶部是一块**小圆盘**，直径 ≈ 30–35% VW，盘心有**很浅的小凹陷**（小坑，非深井）。
- **深度量级：漏斗总高（盘心→底部尖点）≈ 50–60% VH ≈ 1.5–1.8 × 盘直径**（≈3–3.5 × 盘半径）。
  漏斗是「瘦高」的：高度远大于它自己的宽度。
- 喉部：中段是**较长一段近恒宽细管**（管宽 ≈ 盘径的 1/4–1/3），最后 1/4 才急剧收成尖点。
  尖点略伸出球底。
- 井口**无翻边/无唇**：盘心小凹陷→细管是一条平滑 S 曲线过渡。
- 井壁坡度：**近似单坡度长锥（略凹形）**，从上到下缓慢收窄；没有明显的外裙——
  小盘本身就是裙边，过渡带很窄。
- 盘面上方有一层**淡淡的粒子雾**：点云在盘口上方宽缓地散开（轻微上扬），像尘埃被吹起。

### b) 平面（网格地面）的可见范围与边缘处理

- **小漂浮盘**：直径 ≈ 30–35% VW，是三张图里平面最小的。
- 盘缘**软淡出**：网格线在边缘逐渐变疏、变淡直至消失，无硬边、无雾墙；
  圆盘像悬浮在一片空白的浅灰背景里。
- 平面在画面中占比小：盘宽 ≈30% 帧宽，其余大半画面是空白背景。

### c) 球体大小与相对井的位置

- **很小的暗球**（密集线框，视觉上接近黑色剪影），直径 ≈ 3–4% VW。
- 球位于漏斗**尖底**；漏斗尖点在球底下方再延伸一小段。
- **球 : 盘直径 ≈ 1:10 至 1:12** —— 球相对盘面极小。

### d) 机位估计

- **低机位、近平视**：仰角 ≈ 15–25°（polarDeg ≈ 65–75°），从侧前方略俯视。
- **远距离**：整条超长漏斗（盘→尖底）完整入画，左右两侧留大片空白。
- 构图：盘心 ≈32–38% VH；漏斗占画面中央一条垂直带（上端 ≈30–35% 帧宽）；
  球 ≈78–82% VH、水平居中，仅占 ≈3–4% 帧宽。

### e) 让它读作「正常引力势」的关键视觉特征

一块小盘被拉成**超长细漏斗**，底部一个极小的暗球——黑洞感来自漏斗的**极端长宽比
（高/宽 > 3）**、中段那段让人联想到「光也爬不出来」的细长喉管，以及底部极小的球。
注意：参考图是窄视野小盘构图，我们按「保留差异」把盘放大，但**细长比例不变**。

> 实现提示（非硬性）：`funnel` 项给小口径 + 大深度，锥段拉长、中段收窄到细管；
> 平面 `grid.half` 可以缩小成小盘，但我们要按保留差异扩大盘面（见文末）。
> 盘上方的粒子雾可交给 `decor` 的点云表现。

## 5.png — PROCYON B（白矮星）

### a) 井/漏斗整体剖面形状

- **形状族：宽浅碗（bowl）**——没有漏斗、没有喉部、没有尖点，和 3/4 完全相反。
- 凹陷（碗口）直径 ≈ 80–100% VW，**非常宽**。
- **深度量级：碗深（平面水平面→碗底最低点）≈ 10–15% VW，
  深 : 碗口直径 ≈ 1:6 至 1:8**，明显是浅碗。
- 碗底是**宽圆底**，最低点在球底略下方，平滑过渡，无尖点。
- 碗缘**无翻边/无唇**：碗沿以大半径、很缓的曲率融进平面，边界不锐利，
  需要仔细看才分得清「碗到哪结束、平面从哪开始」。
- 井壁坡度：**单坡度、平缓**，且越往外越缓（接近平面处几乎水平）；
  网格线在碗底（球周围）最密，向外逐渐变疏——坡度缓的地方线疏、陡的地方线密。

### b) 平面（网格地面）的可见范围与边缘处理

- **特写：平面铺满整个视口**，四边都延伸出画面——看不到盘缘、看不到地平线，
  整个画面几乎全是网格面。
- 网格间距中等、整体均匀，碗区局部变密；远端（画面上部）因透视压缩线变密。
- 平面在画面中占比 ≈ 90–100%。

### c) 球体大小与相对井的位置

- **大**的密集线框球，直径 ≈ 18–22% VW（≈ 3.png 球的 3 倍、4.png 球的 5–6 倍）。
- 球嵌在**碗底正中**：约**一半球体低于**周围平面水平面（表面下沉到接近球赤道的位置），
  上半球露出；网格在球周围平滑地绕过、汇向碗底。
- **球 : 碗口直径 ≈ 1:4 至 1:5** —— 碗口比球宽得多。

### d) 机位估计

- **低机位、特写**：仰角 ≈ 15–25°（polarDeg ≈ 65–75°），离球很近。
- 构图：球水平居中、垂直 ≈60–65% VH（略低于画面中心）；网格线从球向画面四边辐射展开。
- 球在画面中占 ≈18–22% 帧宽——三者中球最大。

### e) 让它读作「正常引力势」的关键视觉特征

**一颗大星半埋在宽浅的碗里**：凹陷要宽、圆、缓，深只比球半径略深，网格顺着球身平滑
流动而不是钻进尖洞里——整体读作「星体把时空压出一个宽窝」，而不是「掉进黑洞」。
碗形越圆缓、球体越饱满，白矮星这种「强但非极端」的质量感越对。

> 实现提示（非硬性）：用宽半径、浅深度的 `well` / `gauss` 类项即可，
> 避免 `funnel` 尖底；球心高度 `y` 调成约「球半径的一半埋在面下」；
> 相机半径（距离）三者中最小，保证球占帧宽 ≈20%。

## 我们的保留差异（必须遵守）

1. **平面必须清晰可见**：6 个天体都要在视口里清楚看到网格平面。
   - 参考图 3/5 本来就是大平面，直接保持。
   - 参考图 4 是**小盘 + 窄视野**，我们取「**同形状语言 + 更大平面**」：
     盘面直径从参考图的 ≈30% VW 放大到 **≥50% VW**（或延伸到画面边缘、靠雾/透明度淡出），
     同时**保持漏斗的细长比例不变**（漏斗高 ≈ 1.6× 盘面直径、中段细管 + 尖底），
     即「盘变大了，但漏斗仍然是那条细长漏斗」。
2. **保留波浪起伏动画**：平面上我们已有的缓慢起伏/呼吸动画（`surface` 里的 `ctx.t` 项）
   全部保留，以小振幅叠加在上述静态形状之上，不得破坏井的剖面特征。
3. **保留粒子系统**：现有尘埃点 / 贴地小方块 / 螺旋吸入粒子（`decor`）保留；
   参考图 4 盘口上方的粒子雾若现有系统可覆盖则保持现有风格，不新增特效。
4. **线条/配色不变**：不改线色、线宽、底色、雾色与整体 HUD 风格；
   只允许动各 profile 内的 `surface` / `grid` / `camera` / `sphere` / `decor` 参数
   （以及自己 profile 文件内的局部数学函数）。
5. **不完全照抄参考图**：只取参考图的引力势**形状语言**（漏斗细长比、碗的宽缓比、
   球与井的相对大小、低机位构图），不复制参考图的布局、文字与 HUD 元素；
   数值允许在容差内按视觉印象微调。
